# laravel-paypal-licensing
Production-ready модуль интеграции платежной системы PayPal для продажи лицензий на ПО. Разработан на Laravel 12 и PHP 8.5+ с использованием очередей (Redis), атомарных блокировок и сквозного маскирования логов в соответствии с принципами SOLID и стандартами безопасности.
